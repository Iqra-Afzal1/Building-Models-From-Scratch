# Mobile Price Classification using K-Nearest Neighbors (KNN) From Scratch

A complete implementation of the **K-Nearest Neighbors (KNN)** classification algorithm **from scratch using NumPy**.

The project demonstrates how KNN works internally, compares different distance metrics, performs hyperparameter tuning using **5-Fold Cross Validation**, and visualizes the classification results using PCA.

---

## Project Overview

The notebook covers:

- Data preprocessing
- PCA visualization
- Feature scaling
- KNN implementation from scratch
- Euclidean, Manhattan and Minkowski distance metrics
- Hyperparameter tuning (K selection)
- Cross Validation
- Model evaluation
- Prediction visualization
- Sklearn Comparison
