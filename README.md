# Building Models From Scratch

> A collection of Machine Learning and Deep Learning algorithms implemented **from scratch** using Python and NumPy to understand the mathematics, optimization, and implementation behind modern AI.

---

## About

This repository is a personal educational project focused on implementing machine learning models **without relying on machine learning frameworks** for the learning algorithms.

The goal is not only to obtain accurate predictions but to understand **how each algorithm works internally**, from the underlying mathematics to the optimization process.

Every implementation is accompanied by:

- 📖 Mathematical derivations
- 🧠 Step-by-step explanations
- 💻 Clean implementations
- 📊 Interactive visualizations
- 📓 Well-documented notebooks
